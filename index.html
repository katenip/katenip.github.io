Agentic AI · Local inference · Tool integration

Local Agents in 3D Simulated Environments

Configured a local-first development workflow that connects open-weight language models to coding agents and MCP-enabled tools in 3D simulation environments. Agents use project context to inspect and act through editor tools; I review changes and validate behavior in the environment.

  • Run Qwen and GPT-OSS models locally with Ollama; explore model choice, context windows, GPU use, and coding-task response quality.
  • Connect Cline and OpenCode agents to project inspection and editor actions through Model Context Protocol (MCP) servers.
  • Use bounded task planning, prompt and context engineering, iterative debugging, and human review to check generated changes.
Tools: Ollama, Qwen, GPT-OSS, Cline, OpenCode, MCP, Unity
